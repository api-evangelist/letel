# Letel

Shanghai Letel Communication Equipment (Group) Co., Ltd. (上海乐通通信设备（集团）股份有限公司) is a Chinese manufacturer of information and communication network infrastructure, founded in March 1992 and headquartered in Shanghai with over 1,500 employees and 20+ service locations nationwide.

Letel builds data center physical infrastructure — cabinet micromodules, cold aisle micromodules, containerized micromodules, pallet IT cabins, and cabinets — alongside communication cabling equipment, optical communication devices, data communication equipment, broadband access equipment, and structural components for notebooks and servers. It operates through subsidiaries including Zhongle Communication Technology Co., Ltd.
